JDY 实习申请要求

门槛不高：在校生身份 + 27届优先 + 软素质；无硬性专业/成绩/证书要求

🎓 身份 / 学历（硬性）

  • 统招本科 / 硕士 / 博士在校生
  • 毕业时间：2026年10月及之后毕业（国内外高校均可，以毕业证注明时间为准）
  • 全部 78 个岗位均标注"27届优先"，但非排他条件

💼 通用软性要求

  • 对零售、物流、科技、健康等业务有长期投入的初心，积极抗压
  • 开朗乐观，快速适应多元化工作环境
  • 责任感强，擅长多任务、跨部门协同
  • 有好奇心，愿意学新知识新技能

⏱️ 实习时长 / 出勤

  • 78 个岗位 JD 中均未写明每周出勤天数或最短实习时长
  • 官网 JDY 项目页亦无硬性要求
  • 通常由部门 HR 在面试通过后按团队安排沟通

🔄 转正 / 留用路径

  • 表现优异可优先向 JDS / TET / TGT 应届生项目转化
  • 官方口径"应届高留用率"
  • 非应届表现优异可获得 JDS / TET 终面直通卡

投递建议

按背景定制投递组合

金融背景

  • 强专业对口：资金管理 / 会计 / 财务经营分析
  • 想偏业务：金融产品经理 / 商务拓展（金融）
  • 有数据能力加分：商业分析 / 数据分析 / 风控

语言背景

  • 首选组合：采销（电商运营）+ 内容运营 双投
  • 简历突出外语等级、留学/交换、海外社媒与跨境电商内容经验
  • 面试明确表达"想做国际事业群出海电商方向"

金融 + 语言双背景

  • 首推商务拓展（金融）：金融业务线 + 不限专业 + 重沟通表达
  • 次选金融产品经理：专业不硬性要求，商务沟通是明确加分点

时机建议

  • JDY 全年开放、远程面试，可现在就投
  • 27 届投 JDY → 表现优异转 JDS/TET 是顺路径
  • 2026.10–2027.9 毕业的应届生可直接投 JDS，不必绕 JDY
